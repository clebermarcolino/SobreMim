# Sobre Mim - Cleber Marcolino

## Descrição

Este projeto é uma página web pessoal desenvolvida para apresentar informações sobre mim.
## Tecnologias Utilizadas

As seguintes tecnologias foram usadas na construção deste projeto:

*   **Frontend:**
    *   HTML5
    *   CSS3
*   **Fontes:**
    *   Google Fonts (Roboto)
*  **IconArchive.**
*  **Flaticon.**

## Instalação

Como este é um projeto de página web estática, a instalação é bastante simples:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/clebermarcolino/SobreMim.git
    ```
    2.  **Navegue até o diretório do projeto:**
    ```bash
    cd SobreMim.git
    ```
3.  **Abra o arquivo `index.html`:**
    Basta abrir o arquivo `index.html` em seu navegador de internet preferido. Não há necessidade de um servidor local para este projeto simples.
